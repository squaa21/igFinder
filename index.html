igFinder

Scopri chi non ti segue back — senza login

Instagram ti permette di scaricare tutti i tuoi dati direttamente dall'app, senza usare app di terze parti o dare la tua password a nessuno. I file includono la lista completa di followers e following in formato JSON, che puoi poi caricare qui.
Instagram ci mette fino a 48 ore a preparare il file — di solito però arriva entro pochi minuti. Ti manda una notifica quando è pronto.
1
Apri Instagram e vai nelle Impostazioni
Tocca la tua foto profilo in basso a destra, poi l'icona ☰ in alto a destra, poi Impostazioni e privacy.
2
Cerca "Scarica le tue informazioni"
Segui questo percorso:
Impostazioni e privacy → Attività → Scarica le tue informazioni
In alternativa: cerca direttamente Scarica le tue informazioni nella barra di ricerca delle impostazioni.
3
Seleziona "Alcuni tuoi dati"
Scegli Alcuni tuoi dati (non serve scaricare tutto). Cerca e spunta solo Followers e Following sotto la sezione "Connessioni".
4
Scegli formato JSON e scarica
Come formato seleziona JSON (non HTML). Inserisci la tua email e premi Crea file. Riceverai un link via email o notifica.
5
Estrai e carica i file qui
Scarica il file .zip, estrailo. Troverai i file followers_1.json e following.json. Caricali nella scheda Carica file JSON qui sopra.
